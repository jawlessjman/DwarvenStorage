# Dwarven Storage

A Valheim mod for adding an interactive storage system

## Features

Adds a storage system to the game.

- Adds a storage interface
  - That has a storage area
  - Can be upgraded to use other crafting stations to craft
  - Storage space can be expanded with extension upgrade pieces

Items can be crafted from within the storage interface. \
Can be upgraded to use all other crafting stations. \
Storage space can be expanded with extension upgrade pieces.
